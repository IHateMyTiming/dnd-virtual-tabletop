# D&D Virtual Tabletop

A browser-based multiplayer virtual tabletop inspired by D&D-style combat and exploration.

Built with **TypeScript** and **Phaser**.

## Project Status

**Early development**

The project is currently focused on building the core virtual tabletop and map editor.

## Goals

- [ ] 30×30 editable grid
- [ ] Terrain painting and editing
- [ ] Multi-level terrain / elevation
- [ ] Stairs, climbing, jumping, and flying
- [ ] Player and enemy tokens
- [ ] Character movement and movement rules
- [ ] Save and load maps
- [ ] Multiplayer rooms
- [ ] Real-time map synchronization
- [ ] Dice rolling system
- [ ] Dice animations
- [ ] Character sprites and animations

## Technologies

- **TypeScript** — Application and game logic
- **Phaser** — 2D game framework
- **Vite** — Development and build tooling
- **WebSockets** — Planned multiplayer communication
